## ✨ 核心功能

- 🎨 **双主题支持：** 无缝切换深色（Dark）和浅色（Light）模式，并在用户浏览器中保存偏好设置。
- 🌐 **多语言支持（5 种语言）：** 完美支持波斯语 (🇮🇷)、英语 (🇬🇧)、中文 (🇨🇳)、俄语 (🇷🇺) 和土耳其语 (🇹🇷)，并支持 RTL/LTR 布局自动切换。
- 📊 **动态三色环形图：** 根据已用流量阈值，动态显示翡翠绿、暖橙和霓虹红交互式进度环。
- ⏳ **实时倒计时：** 精确显示订阅剩余天数、小时和分钟的实时倒计时。
- 📱 **PWA 渐进式应用：** 支持在 iOS 和 Android 设备上将页面添加至主屏幕（Add to Home Screen）。
- ⚡ **节点筛选与搜索：** 提供即时搜索框以及按 VLESS、VMESS、Trojan 和 Shadowsocks 协议快速筛选。
- 🔐 **单文件纯净架构：** 极简单文件部署，无任何追踪脚本或冗余代码。
