## ✨ Возможности

### 🎨 Светлая и тёмная темы

Умное переключение между светлым и тёмным режимами с сохранением предпочтения пользователя в браузере — при следующем посещении сразу активируется последняя выбранная тема.

---

### 🌐 Многоязычность (5 языков)

Полная поддержка:

| Язык | Регион | Направление |
|:---|:---:|:---:|
| 🇮🇷 Персидский | Иран | RTL |
| 🇬🇧 Английский | Мир | LTR |
| 🇨🇳 Китайский | Китай | LTR |
| 🇷🇺 Русский | Россия | LTR |
| 🇹🇷 Турецкий | Турция | LTR |

Направление страницы (RTL/LTR) устанавливается автоматически.

---

### 📊 Динамический трёхцветный круговой индикатор

Интерактивный индикатор использования с цветовыми маркерами:

- 🟢 **Изумрудно-зелёный** — Низкое использование
- 🟠 **Тёплый оранжевый** — Среднее использование
- 🔴 **Неоново-красный** — Высокое использование

---

### ⏳ Обратный отсчёт в реальном времени

Точный обратный отсчёт, показывающий оставшееся время подписки:

- Оставшиеся дни
- Оставшиеся часы
- Оставшиеся минуты

---

### 📱 Поддержка PWA (установка как приложение)

Поддержка функции «Добавить на главный экран»:

- iOS (Safari)
- Android (Chrome, Firefox)

После установки работает как нативное приложение — иконка, заставка и полноэкранный режим.

---

### ⚡ Поиск и фильтрация конфигураций

- 🔍 **Мгновенный поиск** — начни печатать и сразу увидишь результат
- 🏷 **Быстрые фильтры-чипы** для протоколов:
  - VLESS
  - VMESS
  - Trojan
  - Shadowsocks

### 🚀 Ультралёгкость

- Никаких тяжёлых фреймворков
- Чистый CSS и JS
- Загрузка менее чем за 100 мс

## 🚀 Быстрая установка

Чтобы автоматически установить и развернуть шаблон на панели **3X-UI**, выполни одну команду в терминале сервера:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/acor1/3xui-Tamplate/main/install.sh)
```

---

## 📂 Путь установки

Скрипт автоматически выполняет следующие шаги:

| Шаг | Описание |
|:---|:---|
| 1 | Создаёт директорию, если её нет |
| 2 | Скачивает новый шаблон |
| 3 | Заменяет `sub.html` в панели |
| 4 | Устанавливает правильные права доступа |

### Путь установки

`/etc/x-ui/sub/sub.html`

Скрипт автоматически создаёт директорию, удаляет старый файл и заменяет его новым шаблоном.

---

## 🛠 Ручная установка

Если предпочитаешь установить вручную:

### 1. Скачай файл

```bash
wget https://raw.githubusercontent.com/acor1/3xui-Tamplate/main/sub.html
```

### 2. Создай директорию (если нет)

```bash
sudo mkdir -p /etc/x-ui/sub
sudo chmod 755 /etc/x-ui/sub
```

### 3. Замени

```bash
sudo cp sub.html /etc/x-ui/sub/sub.html
sudo chmod 644 /etc/x-ui/sub/sub.html
```

### 4. Перезапусти

```bash
sudo systemctl restart x-ui
```

## 🔧 Устранение неполадок

### ❌ Шаблон не отображается

```bash
# Проверь, скопирован ли файл
ls -la /etc/x-ui/sub/sub.html

# Перезапусти службу
systemctl restart x-ui

# Посмотри логи
journalctl -u x-ui -n 50
```

### ❌ PWA не работает

PWA требует **HTTPS**. Если панель работает через HTTP, PWA будет отключён.

### ❌ Язык не меняется

Очисти кэш браузера:

```
Ctrl + Shift + Delete
```

### ❌ Тема сбрасывается после обновления

Разреши использование LocalStorage в браузере. В режиме приватного просмотра тема не сохраняется.

### ❌ Скрипт установки выдаёт ошибку

Если возникает ошибка загрузки, сначала проверь подключение сервера к интернету:

```bash
curl -I https://raw.githubusercontent.com/acor1/3xui-Tamplate/main/sub.html
```

Должно вернуться `HTTP/2 200`.
